# Polar Workout Importer

A Chrome extension that creates phased running targets in Polar Flow from workouts generated with [Polar Workout Generator](https://polar-workout-generator.ai.studio/).

The extension is designed to make creating complex running workouts in Polar Flow faster and simpler.

## What it does

Polar Workout Generator converts a plain-text workout description into a structured workout.

For example:

> 2 km warm up, then 6 x 800m at 4:45/km with 2 min recovery, 2 km cool down

The extension receives the generated workout directly from Polar Workout Generator and automatically creates the corresponding Phased Target in Polar Flow.

It supports:

- Time-based phases
- Distance-based phases
- Multiple phases
- Interval and repeat workouts
- Heart Rate zones
- Pace / Speed zones
- Automatic phase numbering
- Automatic navigation to the Polar Flow target creation page
- Scheduling the target for the selected date

Repeat blocks generated by Polar Workout Generator are automatically expanded into individual Polar phases before creation.

## Installation

The extension is not yet available in the Chrome Web Store.

To install it manually:

## Installation

1. Download the latest pre-built extension from
   **Releases → Latest release**.
2. Download `polar-workout-importer-v1.0.0.zip`.
3. Extract the ZIP.
4. Open `chrome://extensions`.
5. Enable **Developer mode**.
6. Click **Load unpacked**.
7. Select the extracted folder containing `manifest.json`.

The **Polar Workout Importer** extension should now appear in Chrome.

## Usage

1. Log in to [Polar Flow](https://flow.polar.com/).
2. Open [Polar Workout Generator](https://polar-workout-generator.ai.studio/).
3. Describe your workout.
4. Click **Generate Workout**.
5. Review or edit the generated workout.
6. Click **Create in Polar Flow**.

The extension will:

1. Open or reuse a Polar Flow tab.
2. Navigate to the Training Target page.
3. Create the phased workout.
4. Apply the appropriate Heart Rate or Pace zones.
5. Add the target to your Polar Flow Diary.

When finished, the Generator displays:

**Target scheduled in Polar Flow ✓**

You do not need to open the extension popup during normal use.

## Privacy

The extension does not request, receive, or store your Polar username or password.

You log in to Polar Flow normally in your browser. The extension operates only within your existing authenticated Polar Flow session.

The extension does not upload your Polar account data or workout history to the developer.

Technical state required while creating a workout is stored locally in Chrome using `chrome.storage.local`.

Polar Workout Generator stores your configured Polar zone preferences locally in your browser.

## Permissions

The extension uses only:

- `storage` — to maintain temporary workout creation state
- `tabs` — to find, open, and navigate the Polar Flow tab
- Access to `https://flow.polar.com/*` — to create the training target

External communication is restricted to:

`https://polar-workout-generator.ai.studio/*`

The extension does not request access to other websites.
